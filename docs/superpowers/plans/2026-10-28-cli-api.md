# planet-port CLI 与本地 REST API 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 spec(docs/superpowers/specs/2026-10-28-cli-api-design.md)定义的 `planet-port` CLI 全部命令,以及支撑开发验证的 REST 契约类型 crate 与 mock daemon。

**Architecture:** 三个 crate 的 Cargo workspace:`planet-port-api`(纯契约:DTO 类型 + 端点构造函数,daemon 与 CLI 共用)、`mockd`(axum 实现的契约 mock,内存状态,供 CLI 联调与后续 GUI 开发)、`planet-port`(clap + ureq 薄客户端,零业务逻辑)。planet 定位优先级链的 ①② 在 CLI 侧(--planet > 环境变量),③④ 在 daemon 侧(mockd 实现同语义)。

**Tech Stack:** Rust stable、clap 4 (derive)、ureq 3(同步 HTTP)、comfy-table 7、axum 0.8 + tokio(仅 mockd)、serde/serde_json、dirs 6。

## Global Constraints(每个任务隐含遵守)

- 唯一需求来源:docs/superpowers/specs/2026-10-28-cli-api-design.md;命令名/参数与 spec §3 完全一致
- CLI 输出语言为英文(对齐 zerotier-cli 风格,如 `200 join OK`);本计划文档与 commit message 为中文
- 退出码:`0` 成功 / `1` 运行错误 / `2` 用法错误与 planet 歧义 / `3` daemon 不在线(提示 `planet-portd is not running (try: planet-port service start)`)
- 定位链:CLI 只做 `--planet` 与 `PLANET_PORT_PLANET` 环境变量的合并;单/多 planet 自动选择与 409 候选由 daemon(mockd)执行
- **不添加自动化测试用例**(用户全局指令 7.1);每个任务以"对 mockd 手动运行命令 + 比对预期输出"验证
- git 命令一律带 `--no-pager`;commit 遵循 Conventional Commits(中文 description + Body,禁止 Co-authored-by)
- **范围裁剪**:`service` 组命令推迟到 daemon 实现计划(其安装目标二进制 planet-portd 尚不存在)
- 依赖许可均为 MIT/Apache

```rust
/// 定位链 ③④:显式指定 → 校验;省略 → 单 running 自动选,多 running 409
fn resolve_planet(
    store: &Store,
    planet: Option<&str>,
) -> Result<String, (StatusCode, Json<ApiError>)> {
    if let Some(p) = planet {
        return match store.planets.iter().find(|x| x.id == p || x.name == p) {
            Some(x) => Ok(x.id.clone()),
            None => Err(err(
                StatusCode::NOT_FOUND,
                "planetNotFound",
                &format!("planet \"{p}\" not found"),
                None,
            )),
        };
    }
    let running: Vec<&PlanetDetail> = store
        .planets
        .iter()
        .filter(|p| p.status == "running")
        .collect();
    match running.len() {
        1 => Ok(running[0].id.clone()),
        0 => Err(err(StatusCode::CONFLICT, "noPlanetRunning", "no running planet; specify ?planet=", None)),
        _ => {
            let candidates = running
                .iter()
                .map(|p| format!("{} ({})", p.name, p.network_count))
                .collect();
            Err(err(
                StatusCode::CONFLICT,
                "planetAmbiguous",
                "multiple running planets; specify ?planet=",
                Some(candidates),
            ))
        }
    }
}

async fn auth_mw(req: Request<Body>, next: Next) -> Response {
    let ok = req
        .headers()
        .get("x-zt1-auth")
        .map(|v| !v.is_empty())
        .unwrap_or(false);
    if ok {
        next.run(req).await
    } else {
        err(StatusCode::UNAUTHORIZED, "unauthorized", "missing X-ZT1-Auth header", None)
            .into_response()
    }
}

fn log_event(store: &mut Store, planet: &str, kind: &str, message: &str) {
    store.events.push(EventEntry {
        planet: planet.into(),
        ts_ms: now_ms(),
        kind: kind.into(),
        message: message.into(),
    });
}

async fn planets_import(
    State(st): State<AppState>,
    Json(body): Json<Value>,
) -> Result<(StatusCode, Json<Value>), (StatusCode, Json<ApiError>)> {
    let has_source = body.get("source").and_then(|v| v.as_str()).is_some();
    let has_container = body.get("container").and_then(|v| v.as_str()).is_some();
    if !has_source && !has_container {
        return Err(err(StatusCode::BAD_REQUEST, "badRequest", "body must contain \"source\" or \"container\"", None));
    }
    let n = st.seq.fetch_add(1, Ordering::SeqCst);
    let mut store = st.inner.lock().unwrap();
    let id = format!("{}", 5000000000u64 + n as u64);
    let name = body
        .get("name")
        .and_then(|v| v.as_str())
        .map(String::from)
        .unwrap_or_else(|| format!("planet-{n}"));
    let detail = PlanetDetail {
        id: id.clone(),
        name,
        icon: "animal.rabbit".into(),
        color: "#59A96A".into(),
        kind: PlanetKind::Custom,
        world_id: 5000000000 + n as u64,
        roots: vec!["9.9.9.9/9993".into()],
        file_size: 1024,
        revision_time_ms: now_ms(),
        last_node_id: None,
        source: if has_container { "qr".into() } else { body["source"].as_str().unwrap().into() },
        network_count: 0,
        port: 10000 + n as u16,
        status: "running".into(),
        online: false,
    };
    log_event(&mut store, &id, "planetImported", &format!("planet \"{}\" imported", detail.name));
    store.planets.push(detail.clone());
    Ok((StatusCode::CREATED, Json(json!({ "planet": detail }))))
}
```

```rust
use planet_port_api::types::ApiError;
use planet_port_api::{token_file, DEFAULT_API_PORT};
use serde_json::Value;

pub enum CliError {
    Offline,
    Api(u16, ApiError),
    Usage(String),
    Io(String),
}

impl CliError {
    pub fn exit_code(&self) -> i32 {
        match self {
            CliError::Offline => 3,
            // planet 歧义(409 + 候选)与用法错误同为退出码 2
            CliError::Api(409, e) if e.candidates.is_some() => 2,
            CliError::Api(..) => 1,
            CliError::Usage(_) => 2,
            CliError::Io(_) => 1,
        }
    }
}

pub struct Client {
    agent: ureq::Agent,
    base: String,
    token: String,
}

impl Client {
    pub fn new(api_url: Option<String>) -> Result<Self, CliError> {
        let base = match api_url {
            Some(u) => u.trim_end_matches('/').to_string(),
            None => format!("http://127.0.0.1:{DEFAULT_API_PORT}"),
        };
        let token = match std::env::var("PLANET_PORT_TOKEN") {
            Ok(t) if !t.is_empty() => t,
            _ => std::fs::read_to_string(token_file())
                .map_err(|_| {
                    CliError::Usage(format!(
                        "token file not found: {} (dev: set PLANET_PORT_TOKEN)",
                        token_file().display()
                    ))
                })?
                .trim()
                .to_string(),
        };
        let agent = ureq::Agent::new_with_config(
            ureq::Config::builder().http_status_as_error(false).build(),
        );
        Ok(Self { agent, base, token })
    }

    fn request(
        &self,
        method: &str,
        path: &str,
        body: Option<&Value>,
    ) -> Result<(u16, String), CliError> {
        let url = format!("{}{}", self.base, path);
        let mut req = self
            .agent
            .request(method, &url)
            .header("X-ZT1-Auth", &self.token);
        let resp = match body {
            Some(b) => req.header("Content-Type", "application/json").send_json(b.clone()),
            None => req.call(),
        };
        // 连接失败统一视为 daemon 不在线(退出码 3)
        let resp = resp.map_err(|_| CliError::Offline)?;
        let status = resp.status().as_u16();
        let text = resp
            .body_mut()
            .read_to_string()
            .map_err(|e| CliError::Io(e.to_string()))?;
        Ok((status, text))
    }

    fn parse(&self, code: u16, text: String) -> Result<Value, CliError> {
        if (200..300).contains(&code) {
            Ok(serde_json::from_str(&text).unwrap_or(Value::Null))
        } else {
            let api = serde_json::from_str(&text).unwrap_or(ApiError {
                error: format!("http{code}"),
                message: text,
                candidates: None,
            });
            Err(CliError::Api(code, api))
        }
    }

    pub fn get_json(&self, path: &str) -> Result<Value, CliError> {
        let (c, t) = self.request("GET", path, None)?;
        self.parse(c, t)
    }
    pub fn post_empty(&self, path: &str) -> Result<Value, CliError> {
        let (c, t) = self.request("POST", path, None)?;
        self.parse(c, t)
    }
    pub fn post_json(&self, path: &str, body: &Value) -> Result<Value, CliError> {
        let (c, t) = self.request("POST", path, Some(body))?;
        self.parse(c, t)

        let (c, t) = self.request("PATCH", path, Some(body))?;

    }
    pub fn delete(&self, path: &str) -> Result<Value, CliError> {
        let (c, t) = self.request("DELETE", path, None)?;
        self.parse(c, t)
    }
    pub fn get_bytes(&self, path: &str) -> Result<Vec<u8>, CliError> {
        let url = format!("{}{}", self.base, path);
        let resp = self
            .agent
            .request("GET", &url)
            .header("X-ZT1-Auth", &self.token)
            .call()
            .map_err(|_| CliError::Offline)?;
        if !resp.status().is_success() {
            return Err(CliError::Offline);
        }
        let mut buf = Vec::new();
        resp.body_mut()
            .read_to_end(&mut buf)
            .map_err(|e| CliError::Io(e.to_string()))?;
        Ok(buf)
    }
```

```rust
pub fn set(
    client: &Client,
    nwid: &str,
    values: &[String],
    planet: &Option<String>,
    json: bool,
) -> Result<(), CliError> {
    let mut body = serde_json::Map::new();
    for v in values {
        let (k, val) = v
            .split_once('=')
            .ok_or_else(|| CliError::Usage(format!("expected key=value, got \"{v}\"")))?;
        match k {
            "routeViaZeroTier" => {
                body.insert(k.into(), json!(val == "1"));

            "dnsMode" => {
                if !matches!(val, "none" | "network" | "custom") {
                    return Err(CliError::Usage(format!(

                    )));
                }
                body.insert(k.into(), json!(val));
            }
            "customDns" => {
                let list: Vec<String> = val.split(',').map(|s| s.trim().to_string()).filter(|s| !s.is_empty()).collect();

            }
            _ => {

            }
        }
    }

    ok(200, "set", json, &resp);
    Ok(())
```

```rust
const FALLBACK: &str = "🪐";

pub fn icon_to_emoji(icon: &str) -> &'static str {
    let key = icon.strip_prefix("animal.").unwrap_or(icon);
    EMOJI
        .iter()
        .find(|(k, _)| *k == key)
        .map(|(_, e)| *e)
        .unwrap_or(FALLBACK)
```

```rust
use crate::client::{CliError, Client};
use crate::emoji::icon_to_emoji;
use crate::output::{new_table, print_json};
use clap::Subcommand;
use planet_port_api::endpoints;
use planet_port_api::types::{PlanetDetail, PlanetStatus, ShareLink};
use serde_json::{json, Value};
use std::io::Write;

#[derive(Subcommand)]
pub enum PlanetCmd {
    /// List registered planets
    List,
    /// Import planet from file path or URL
    Import {
        source: String,
        /// Optional alias
        #[arg(long)]
        name: Option<String>,
    },
    /// Show planet details
    Show { id: String },
    /// Rename a planet
    Rename { id: String, new_name: String },
    /// Start a stopped planet
    Start { id: String },
    /// Stop a planet (keep registered)
    Stop { id: String },
    /// Remove a planet registration
    Rm {
        id: String,
        /// Skip confirmation (scripts)
        #[arg(long)]
        yes: bool,
    },
    /// Export planet binary to stdout or file
    Export {
        id: String,
        #[arg(short, long)]
        out: Option<String>,
    },
    /// Create a LAN temporary download link
    Share {
        #[arg(long, default_value_t = 300)]
        ttl: u64,
        id: String,
    },
}

pub fn run(client: &Client, cmd: &PlanetCmd, json: bool) -> Result<(), CliError> {
    match cmd {
        PlanetCmd::List => list(client, json),
        PlanetCmd::Import { source, name } => import(client, source, name.clone(), json),
        PlanetCmd::Show { id } => show(client, id, json),
        PlanetCmd::Rename { id, new_name } => rename(client, id, new_name, json),
        PlanetCmd::Start { id } => {
            let resp = client.post_empty(&endpoints::planet_action(id, "start"))?;
            print_result("start", json, &resp);
            Ok(())
        }
        PlanetCmd::Stop { id } => {
            let resp = client.post_empty(&endpoints::planet_action(id, "stop"))?;
            print_result("stop", json, &resp);
            Ok(())
        }
        PlanetCmd::Rm { id, yes } => rm(client, id, *yes, json),
        PlanetCmd::Export { id, out } => export(client, id, out.clone()),
        PlanetCmd::Share { id, ttl } => share(client, id, *ttl, json),
    }
}

fn print_result(verb: &str, json: bool, body: &Value) {
    if json {
        print_json(body);
    } else {
        println!("200 {verb} OK");
    }
}

fn list(client: &Client, json: bool) -> Result<(), CliError> {
    let v = client.get_json(endpoints::planets())?;
    if json {
        print_json(&v);
        return Ok(());
    }
    let rows: Vec<PlanetStatus> = serde_json::from_value(
        v.get("planets").cloned().unwrap_or(Value::Null),
    )
    .unwrap_or_default();
    let mut t = new_table(&["ICON", "PLANET", "ID", "STATUS", "NETWORKS", "PORT"]);
    for p in rows {
        t.add_row(vec![
            icon_to_emoji(&p.icon).to_string(),
            p.name,
            p.id,
            if p.status == "running" { "running".into() } else { "stopped".into() },
            p.network_count.to_string(),
            p.port.to_string(),
        ]);
    }
    println!("{t}");
    Ok(())
}

fn import(
    client: &Client,
    source: &str,
    name: Option<String>,
    json: bool,
) -> Result<(), CliError> {
    let body = json!({ "source": source, "name": name });
    let resp = client.post_json(endpoints::planets(), &body)?;
    if json {
        print_json(&resp);
        return Ok(());
    }
    let d: PlanetDetail = serde_json::from_value(
        resp.get("planet").cloned().unwrap_or(Value::Null),
    )
    .map_err(|e| CliError::Io(e.to_string()))?;
    println!("imported planet \"{}\" (id {}) → running", d.name, d.id);
    Ok(())
}

fn show(client: &Client, id: &str, json: bool) -> Result<(), CliError> {
    let v = client.get_json(&endpoints::planet(id))?;
    if json {
        print_json(&v);
        return Ok(());
    }
    let d: PlanetDetail = serde_json::from_value(
        v.get("planet").cloned().unwrap_or(Value::Null),
    )
    .map_err(|e| CliError::Io(e.to_string()))?;
    println!("planet    {} {}", icon_to_emoji(&d.icon), d.name);
    println!("id        {}", d.id);
    println!("worldId   {}", d.world_id);
    println!("type      {:?}", d.kind);
    println!("status    {} (online: {})", d.status, d.online);
    println!("roots     {}", d.roots.join(", "));
    println!("source    {}", d.source);
    println!("size      {} bytes", d.file_size);
    println!("revision  {} (ms epoch)", d.revision_time_ms);
    println!("lastNodeId {}", d.last_node_id.unwrap_or_else(|| "—".into()));
    println!("networks  {}", d.network_count);
    println!("port      {}", d.port);
    Ok(())
}

fn rename(client: &Client, id: &str, new_name: &str, json: bool) -> Result<(), CliError> {
    let body = json!({ "name": new_name });
    let resp = client.patch_json(&endpoints::planet(id), &body)?;
    print_result("rename", json, &resp);
    Ok(())
}

fn rm(client: &Client, id: &str, yes: bool, json: bool) -> Result<(), CliError> {
    if !yes {
        print!("delete planet \"{}\" and its config? [y/N] ", id);
        std::io::stdout().flush().ok();
        let mut answer = String::new();
        std::io::stdin()
            .read_line(&mut answer)
            .map_err(|e| CliError::Io(e.to_string()))?;
        if !answer.trim().eq_ignore_ascii_case("y") {
            println!("aborted");
            return Ok(());
        }
    }
    let _ = client.delete(&endpoints::planet(id))?;
    print_result("rm", json, &Value::Null);
    Ok(())
}

fn export(client: &Client, id: &str, out: Option<String>) -> Result<(), CliError> {
    let bytes = client.get_bytes(&endpoints::planet_export(id))?;
    match out {
        Some(path) => std::fs::write(path, &bytes).map_err(|e| CliError::Io(e.to_string()))?,
        None => std::io::stdout()
            .write_all(&bytes)
            .map_err(|e| CliError::Io(e.to_string()))?,
    }
    Ok(())
}

fn share(client: &Client, id: &str, ttl: u64, json: bool) -> Result<(), CliError> {
    let body = json!({ "ttlSeconds": ttl });
    let resp = client.post_json(&endpoints::planet_share(id), &body)?;
    if json {
        print_json(&resp);
        return Ok(());
    }
    let link: ShareLink = serde_json::from_value(resp)
        .map_err(|e| CliError::Io(e.to_string()))?;
    println!("{}", link.url);
    eprintln!("expires_at: {}", link.expires_at);
    Ok(())
}
```

```rust
use crate::client::{CliError, Client};
use crate::output::{new_table, print_json};
use planet_port_api::endpoints;
use planet_port_api::types::{EventEntry, PlanetStatus};
use serde_json::Value;
use std::thread::sleep;
use std::time::Duration;

pub fn use_planet(client: &Client, planet: &str) -> Result<(), CliError> {
    let v = client.get_json(endpoints::planets())?;
    let rows: Vec<PlanetStatus> = serde_json::from_value(
        v.get("planets").cloned().unwrap_or(Value::Null),
    )
    .unwrap_or_default();
    let found = rows
        .iter()
        .find(|p| p.id == planet || p.name == planet)
        .ok_or_else(|| CliError::Usage(format!("planet \"{planet}\" not found")))?;
    // stdout 只输出 export 行(供 eval);提示走 stderr
    println!("export PLANET_PORT_PLANET={}", found.id);
    eprintln!("# default planet set to \"{}\" (this shell only)", found.name);
    eprintln!("# usage: eval $(planet-port use {})", found.name);
    Ok(())
}

pub fn events(
    client: &Client,
    planet: &Option<String>,
    limit: usize,
    follow: bool,
    json: bool,
) -> Result<(), CliError> {
    if !follow {
        let v = client.get_json(&endpoints::events(planet.as_deref(), limit, None))?;
        if json {
            print_json(&v);
            return Ok(());
        }
        render(&v);
        return Ok(());
    }
    // --follow:2s 轮询,按 ts 游标增量输出
    let mut after: Option<u64> = None;
    loop {
        let v = client.get_json(&endpoints::events(planet.as_deref(), limit, after))?;
        let entries: Vec<EventEntry> = serde_json::from_value(
            v.get("events").cloned().unwrap_or(Value::Null),
        )
        .unwrap_or_default();
        if let Some(last) = entries.iter().map(|e| e.ts_ms).max() {
            after = Some(last);
        }
        if json {
            print_json(&v);
        } else if !entries.is_empty() {
            render(&v);
        }
        sleep(Duration::from_secs(2));
    }
}

fn render(v: &Value) {
    let entries: Vec<EventEntry> = serde_json::from_value(
        v.get("events").cloned().unwrap_or(Value::Null),
    )
    .unwrap_or_default();
    let mut t = new_table(&["TS", "PLANET", "KIND", "MESSAGE"]);
    for e in entries {
        t.add_row(vec![
            e.ts_ms.to_string(),
            e.planet,
            e.kind,
            e.message,
        ]);
    }
    println!("{t}");
}
```
